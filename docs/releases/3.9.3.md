# jps Telephone 3.9.3 (176)

- Fix an Apple silicon crash when placing calls by aligning atomic allocations in PJSIP.
- Prefer IPv6 automatically when the SIP next hop has a native IPv6 address and the Mac has an IPv6 route to it. Use IPv4 for IPv4-only destinations. SIP and the initial audio offer use the selected address family.
- Remove the per-account IP version selector. IPv4 NAT settings remain available. An IPv6 SIP request that times out is not automatically replayed over IPv4.

The owner tested the preceding dual-stack candidate on the office Mac and approved publication. This release adds version metadata and release documentation to the tested application code.

Apple silicon, macOS 15.6 or later. The app is ad-hoc signed and unnotarised. See BUILD-VERIFICATION.md for the local release checks and SHA256SUMS.txt for the download checksums.
